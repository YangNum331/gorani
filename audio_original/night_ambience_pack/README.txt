GORANI night ambience pack
Source: user-provided file 'freesound_community-night-ambience-17064.mp3'

Files:
- night_ambience_full_clean.wav : cleaned full-length source
- night_ambience_loop_90s.wav : loop-friendly ~90s stereo WAV
- night_ambience_loop_90s.ogg : same loop, smaller file size

Processing:
- 48 kHz stereo
- very light 60 Hz high-pass and 16 kHz low-pass cleanup
- conservative peak level for background use
- loop version uses a 4-second seam crossfade

Godot suggestion:
- Use AudioStreamPlayer (not 3D)
- Enable looping on the imported stream/resource
- Start around -12 to -20 dB in-game and adjust by ear
